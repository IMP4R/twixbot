# TWIX — Telegram CRM для P2P USDT

CRM-платформа в Telegram для обмена USDT между клиентами и менеджерами. Бот выступает мостиком: ведёт заявки, распределяет менеджеров, считает прибыль и статистику. Оплата происходит напрямую в ЛС Telegram.

---

## Быстрый старт

1. **Установка зависимостей:**
   ```bash
   pip install aiogram python-dotenv
   ```

2. **Настройка окружения:**
   ```bash
   cp .env.example .env
   # Отредактируй .env: BOT_TOKEN, ADMIN_IDS
   ```

3. **Запуск:**
   ```bash
   python3 main.py
   ```

---

## Что умеет бот

### Клиент
- Создаёт сделку с фиксированным курсом
- Видит актуальные tier-курсы (до 100 USDT → 84 ₽, до 300 → 85 ₽ ...)
- Получает контакт менеджера
- Смотрит профиль, историю, тикеты

### Менеджер
- Получает сделки автоматически (round robin)
- Работает в привычном Telegram-чате через команды: `+cr 200`, `-d`, `-c`, `+p`, `-transfer`
- Видит статистику и настройки

### Администратор
- Управляет курсами (редактирование, сдвиг ±1 всей сетки)
- Добавляет/деактивирует менеджеров
- Смотрит статистику, логи, делает rollback
- Запускает розыгрыши тикетов
- Редактирует шаблоны сообщений и настройки runtime

## Структура проекта

```
bot/           # Telegram handlers, keyboards, middleware
docs/          # Документация
settings/      # Runtime-настройки с авто-админкой
tests/         # 138 тестов (settings, tpl, core)
tpl/           # Шаблоны, локализация, авто-админка шаблонов
database.py    # SQLite (WAL, Decimal, UUID, soft delete)
models.py      # Датаклассы сущностей
repositories.py # CRUD + soft delete
services.py    # Бизнес-логика (курсы, сделки, очереди, audit)
config.py      # .env конфигурация
main.py        # Точка входа
```
